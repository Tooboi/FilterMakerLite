# Filter Maker Lite 0.6.6

The first release of **Filter Maker Lite**, the free edition of [Filter Maker Pro](https://github.com/Tooboi/FilterMakerPro). Make pleated air filters in Blender from a line, a curve, mesh edges or faces. There's no node setup; everything is in the N-panel.

## ✨ What's included

- **Four ways to start:** *New Filter Line*, any curve (open or closed), selected mesh edges, or selected faces. Neighbouring faces become one continuous pleated sheet that runs around corners.
- **Pleat shaping:** density, depth, offset, pleat angle, surface detail, height and direction, and optional thickness.
- **Pleat bevel** with cuts, from sharp paper folds to soft rounded media.
- **Clean topology:** a structured quad grid with welded seams and smooth normals across panel joins, or triangles if you prefer.
- **A clean border:** a flat frame with the width you choose, sealed so the pleat ends never poke through, including at corners and folds.
- **Live editing:** sliders rebuild the filter as you drag, and curve sources stay editable.

## ⭐ Want more? Filter Maker Pro adds

- Wear (Clouds displace) for a used look
- Hair and dust, shared across all your filters
- Chamfer, Round and Lip borders, overhang and front / back extend
- A boolean cutter
- Presets, built-in and your own

**Upgrading keeps your work:** filters made in Lite open in Pro with every setting intact. The **Filter Maker Pro** panel inside Lite links to it.

## 📦 Install

**Requires Blender 4.2 LTS or newer** (tested on 5.2 LTS).

1. Download **`FilterMakerLite-0.6.6.zip`** below. Don't unzip it.
2. Drag it into Blender, or go to *Edit → Preferences → Get Extensions → ⌄ → Install from Disk…*
   (Legacy: *Add-ons → Install from Disk…*, then enable **Object: Filter Maker Lite**.)
3. Press <kbd>N</kbd> in the 3D Viewport and open the **Filter Maker** tab.

> [!NOTE]
> Lite and Pro can't be enabled at the same time. If Pro is enabled, disable it first; Blender shows a message if both are on.
