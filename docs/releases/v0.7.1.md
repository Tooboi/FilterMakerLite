# Filter Maker Lite 0.7.1

The free pleated filter generator for Blender now includes the **Boolean tool**, so you can set a filter into your model without leaving the add-on.

<p align="center">
  <img src="https://raw.githubusercontent.com/Tooboi/FilterMakerLite/main/docs/images/boolean.png" alt="A filter set into a housing with the Boolean tool" width="80%">
</p>

## ✨ New

- **Boolean tool:** cut the source mesh with a box, an envelope of the pleated form or any object. Make a filter *From Faces* on a housing, turn on **Boolean** (Envelope, Difference), and the housing is cut around it. The cut is applied when you click **Finish (Bake)**.
- **UVs unrolled across the folds:** textures keep their size on every pleat flank and on the frame.
- **Apply Curve Edit:** reshape a curve source in Edit Mode, then click **Apply Curve Edit** in the panel to rebuild the filter.

## 🔄 Changed

- Curve sources are no longer followed by a background handler, so Blender does no extra work on every scene change. After editing a curve, click **Apply Curve Edit** (or the Update button).
- The add-on is fully self-contained: it holds only its own features and doesn't check for other add-ons.
- Faster rebuilds of face and curve filters.

## 📦 Install

**Requires Blender 4.2 LTS or newer** (tested on 5.2 LTS).

- **From Blender:** *Edit → Preferences → Get Extensions*, search for **Filter Maker Lite** and click **Install**.
- **From GitHub:** download **`FilterMakerLite-0.7.1.zip`** below (don't unzip it) and drag it into Blender, or use *Get Extensions → ⌄ → Install from Disk…*

Then press <kbd>N</kbd> in the 3D Viewport and open the **Filter Maker** tab.
