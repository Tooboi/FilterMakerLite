# Changelog

Filter Maker Lite follows the version of Filter Maker Pro it is built from.

## [0.6.6]

- First release of Filter Maker Lite, the free edition of Filter Maker Pro.
- All sources (new line, curve, mesh edges, faces), pleat shaping, pleat bevel, quads / tris, shading and a flat border.
- Filters made in Lite open in Filter Maker Pro with all their settings.
